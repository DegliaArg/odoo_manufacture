To configure this module you need to:

#. Go to *Manufacturing > Configuration > Settings*.
#. In the *Operations* section, enable *Group MOs on creation*.
#. Set the *Grouping window (± days)*: the number of days, before and after the
   scheduled start date, within which an existing order is considered a
   grouping target. ``0`` means the same day only.

The feature is disabled by default and can be turned off at any time without
uninstalling the module.
